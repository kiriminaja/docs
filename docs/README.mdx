# KiriminAja Mitra API

KiriminAja Mitra API is our shipping integration product that lets your platform check rates, create orders, request pickups, and track deliveries — all through a single API.

| Environment | Base URL                      |
| ----------- | ----------------------------- |
| Sandbox     | https://tdev.kiriminaja.com   |
| Production  | https://client.kiriminaja.com |

## What You Can Build

- **Check rates** — Compare shipping costs across 15+ couriers
- **Create orders** — Generate AWB numbers for express and instant delivery
- **Request pickups** — Schedule courier pickups from your location
- **Track shipments** — Monitor delivery status via webhook or polling
- **Manage payments** — Handle COD and non-COD payment flows

## Quick Start

The fastest way to explore the API is through our Postman Collection.

1. Install [Postman](https://learning.postman.com/docs/getting-started/installation-and-updates/)
2. Download the [KiriminAja Mitra API Postman Collection](https://drive.google.com/drive/folders/1ZcqsQLdx9ZAGnKFBaw2It5dqOUbCQdht?usp=sharing)
3. Import the collection into Postman
4. Get your API Key (see below)
5. Set the `api_key` variable in the collection to your Sandbox API key

## How to Get Your API Key

1. Register at the [Sandbox Dashboard](https://sandbox.kiriminaja.com/)
2. Complete the registration form
3. Log in to the [Sandbox Dashboard](https://sandbox.kiriminaja.com/login)
4. Wait for account approval
5. Go to **Integrasi** and copy your API Key

## Authentication

Include your API key in every request:

| Header          | Value          |
| --------------- | -------------- |
| `Accept`        | application/json |
| `Content-Type`  | application/json |
| `Authorization` | Bearer `{api_key}` |
