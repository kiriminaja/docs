## Installation

::code-group

```bash [php]
compose require kiriminaja/kiriminaja-php
```

```bash [bun]
bun add kiriminaja
```

```bash [go]
go get github.com/kiriminaja/go
```

```bash [python]
pip install kiriminaja
```

```bash [ruby]
gem install kiriminaja
```

::
